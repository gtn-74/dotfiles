# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## keybinds

基本:

- j - 1 行下
- 5j - 5 行下（数字 + j で指定した行数下に移動）
- 10j - 10 行下

その他の下移動:

- Ctrl-d - 半画面分下にスクロール
- Ctrl-f - 1 画面分下にスクロール

例えば「3 行下に移動したい」なら 3j と入力します。

⏺ nvim でウィンドウ間を移動するコマンドです:

基本のウィンドウ移動:

- Ctrl-w + h - 左のウィンドウへ
- Ctrl-w + l - 右のウィンドウへ
- Ctrl-w + j - 下のウィンドウへ
- Ctrl-w + k - 上のウィンドウへ

簡単な方法:

- Ctrl-w + w - 次のウィンドウへ順番に移動

サイドバーが左にある場合、Ctrl-w l でファイルへ、Ctrl-w h でサイドバーへ戻れます。

覚え方: Ctrl-w (window の意味) + 移動方向 (hjkl)

    nvim-treeの便利なコマンドをいくつか紹介します:

表示切り替え:

- H - 隠しファイル表示/非表示
- I - gitignore されたファイル表示/非表示
- R - ツリーをリフレッシュ

ファイル操作:

- a - 新しいファイル/ディレクトリ作成
- d - 削除
- r - 名前変更
- x - カット
- c - コピー
- p - ペースト

ナビゲーション:

- Enter - ファイルを開く/ディレクトリを展開
- o - ファイルを開く（別の方法）
- - - 親ディレクトリに移動
- P - 親ノードに移動

その他:

- ? - ヘルプを表示（全コマンド確認）
- g? も同じくヘルプ

neovim でファイルを削除する方法です:

1. nvim-tree（サイドバー）を使う方法（一番簡単）:

- サイドバーで削除したいファイルにカーソルを合わせる
- d キーを押す
- 確認メッセージが出るので、y で確定

2. コマンドラインから削除:

- :!rm ファイル名 - シェルコマンドで削除
- :!trash ファイル名 - ゴミ箱に移動（trash コマンドがインストールされている場合）
