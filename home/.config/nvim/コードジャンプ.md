# コードジャンプ（LSP）

LazyVim で TypeScript のコードジャンプを使うための前提とキーマップ。

## 前提: 拡張の有効化（最初の1回だけ）

`:LazyExtras` を開いて以下に `x` で有効化:

- **`lang.typescript`** → LSP(`vtsls`) ＝ コードジャンプ・補完・型表示

有効化後に nvim を再起動。Mason が `vtsls` を自動インストールする。

- 進捗確認: `:Mason`
- attach 確認: `:LspInfo`（`vtsls` が attached になっていれば OK）

> 直接書き換える場合は `~/.config/nvim/lazyvim.json` の `"extras": []` に
> `"lazyvim.plugins.extras.lang.typescript"` を足す。

## キーマップ

| キー | 動作 |
|------|------|
| `gd` | 定義へジャンプ |
| `gr` | 参照一覧（この関数どこで使われてる？） |
| `gI` | 実装へジャンプ |
| `gy` | 型定義へジャンプ |
| `K`  | ホバー（型・ドキュメント表示） |
| `<C-o>` / `<C-i>` | ジャンプ元へ戻る / 進む（一番使う） |
| `<leader>cr` | リネーム（全箇所一括） |
| `<leader>ca` | コードアクション（import 追加など） |
| `]d` / `[d` | 次／前の診断（エラー）へ |
| `<leader>ss` | ファイル内シンボル一覧（関数へ飛ぶ） |

`gd` で飛んで `<C-o>` で戻る、の往復が基本リズム。

## つまずきやすい点

- **`gd` が効かない** → extras 未反映。`:LazyExtras` で `lang.typescript` を有効化＆再起動できているか、`:Mason` で `vtsls` が ✓ か確認。
