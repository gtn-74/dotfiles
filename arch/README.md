# Arch Linux (Hyprland) ショートカット一覧

> **Super キー** = Windows マークのキー

---

## Hyprland

### アプリ起動

| キー | 動作 |
|------|------|
| `Super + Q` | ターミナル (WezTerm) 起動 |
| `Super + E` | ファイルマネージャー (Nautilus) 起動 |
| `Super + R` | アプリランチャー |

### ウィンドウ操作

| キー | 動作 |
|------|------|
| `Super + C` | ウィンドウを閉じる |
| `Super + V` | フローティング切り替え |
| `Super + F` | フルスクリーン切り替え |
| `Super + P` | 疑似タイリング切り替え |
| `Super + J` | レイアウト切り替え |

### フォーカス移動

| キー | 動作 |
|------|------|
| `Super + ←` | 左のウィンドウへ |
| `Super + →` | 右のウィンドウへ |
| `Super + ↑` | 上のウィンドウへ |
| `Super + ↓` | 下のウィンドウへ |

### ワークスペース

| キー | 動作 |
|------|------|
| `Super + 1〜0` | ワークスペース切り替え |
| `Super + Shift + 1〜0` | ウィンドウをワークスペースへ移動 |
| `Super + S` | スペシャルワークスペース表示/非表示 |
| `Super + Shift + S` | ウィンドウをスペシャルワークスペースへ移動 |
| `Super + マウスホイール` | ワークスペースを前後に切り替え |

### マウス操作

| 操作 | 動作 |
|------|------|
| `Super + 左ドラッグ` | ウィンドウを移動 |
| `Super + 右ドラッグ` | ウィンドウをリサイズ |

### システム

| キー | 動作 |
|------|------|
| `Super + M` | シャットダウンメニュー |
| `音量 Up/Down` | 音量 ±5% |
| `音量ミュート` | ミュート切り替え |
| `マイクミュート` | マイクミュート切り替え |
| `輝度 Up/Down` | 画面の明るさ調整 |
| `メディアキー` | 再生/停止/次/前 |

---

## Nautilus (ファイルマネージャー)

### 表示

| キー | 動作 |
|------|------|
| `F9` | サイドバー表示/非表示 |
| `F11` | フルスクリーン切り替え |
| `Ctrl + H` | 隠しファイル表示切り替え |
| `Ctrl + 1` | アイコン表示 |
| `Ctrl + 2` | リスト表示 |
| `Ctrl + +` | ズームイン（アイコンを大きく）|
| `Ctrl + -` | ズームアウト（アイコンを小さく・より多く表示）|
| `Ctrl + 0` | ズームリセット |

### ナビゲーション

| キー | 動作 |
|------|------|
| `Alt + ←` | 戻る |
| `Alt + →` | 進む |
| `Alt + ↑` | 親フォルダへ |
| `Ctrl + L` | アドレスバーに入力 |
| `Ctrl + F` | 検索 |

### タブ・ウィンドウ

| キー | 動作 |
|------|------|
| `Ctrl + T` | 新規タブ |
| `Ctrl + N` | 新規ウィンドウ |
| `Ctrl + W` | タブを閉じる |

### ファイル操作

| キー | 動作 |
|------|------|
| `F2` | ファイル名変更 |
| `Ctrl + A` | 全選択 |
| `Ctrl + C` | コピー |
| `Ctrl + X` | 切り取り |
| `Ctrl + V` | 貼り付け |
| `Ctrl + Z` | 元に戻す |
| `Delete` | ゴミ箱に移動 |
| `Shift + Delete` | 完全削除 |
| `Enter` | 開く |
