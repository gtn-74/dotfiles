## WezTerm 設定概要

### 基本設定 (`wezterm.lua`)

#### 外観設定

| 設定項目 | 値 | 説明 |
|---------|-----|------|
| `font_size` | 12.0 | フォントサイズ |
| `window_background_opacity` | 0.60 | ウィンドウの透明度（0-1）|
| `macos_window_background_blur` | 20 | macOSのぼかし効果 |
| `window_decorations` | "RESIZE" | タイトルバーを非表示にしてリサイズのみ可能 |

#### タブバー設定

- `show_tabs_in_tab_bar`: タブバーを表示
- `hide_tab_bar_if_only_one_tab`: タブが1つの時はタブバーを非表示
- `show_new_tab_button_in_tab_bar`: タブ追加ボタンを非表示
- タブバーは透過設定され、カスタムデザインが適用されています

#### その他

- `use_ime`: 日本語入力（IME）を有効化
- `automatically_reload_config`: 設定ファイルの自動リロード

## WezTerm キーバインド一覧

### Leader キーについて

WezTermでは **Leader キー** を使用します：
- **Leader キー**: `Ctrl + q`
- Leader キーを押してから2秒以内に次のキーを押すことで、様々な操作が実行できます

### Workspace（ワークスペース）管理

| キー | 説明 |
|------|------|
| `Leader` + `w` | ワークスペース一覧を表示・切り替え |
| `Leader` + `$` | 現在のワークスペース名を変更 |
| `Leader` + `Shift` + `W` | 新しいワークスペースを作成 |

### Tab（タブ）操作

| キー | 説明 |
|------|------|
| `Cmd` + `t` | 新しいタブを作成 |
| `Cmd` + `w` | 現在のタブを閉じる（確認あり）|
| `Ctrl` + `Tab` | 次のタブへ移動 |
| `Ctrl` + `Shift` + `Tab` | 前のタブへ移動 |
| `Cmd` + `1`〜`9` | タブ番号で直接移動（9は最後のタブ）|
| `Leader` + `{` | タブを左に移動 |
| `Leader` + `}` | タブを右に移動 |

### Pane（ペイン）操作

#### ペイン分割

| キー | 説明 |
|------|------|
| `Leader` + `d` | 縦に分割（下に新しいペイン）|
| `Leader` + `r` | 横に分割（右に新しいペイン）|
| `Leader` + `x` | 現在のペインを閉じる（確認あり）|

#### ペイン移動

| キー | 説明 |
|------|------|
| `Leader` + `h` | 左のペインへ移動 |
| `Leader` + `j` | 下のペインへ移動 |
| `Leader` + `k` | 上のペインへ移動 |
| `Leader` + `l` | 右のペインへ移動 |
| `Ctrl` + `Shift` + `[` | ペイン選択モード |
| `Leader` + `z` | 現在のペインを最大化/元に戻す |

#### ペインリサイズ

1. `Leader` + `s` でリサイズモードに入る
2. `h`, `j`, `k`, `l` でペインサイズを調整
3. `Enter` でリサイズモードを終了

### コピーモード

**コピーモード**は、マウスを使わずにキーボードだけでテキストをコピーできる機能です（Vimライクな操作）。

#### コピーモードの開始

| キー | 説明 |
|------|------|
| `Leader` + `[` | コピーモードを開始 |

#### コピーモード内の移動

| キー | 説明 |
|------|------|
| `h`, `j`, `k`, `l` | 左、下、上、右に移動 |
| `w` | 次の単語へ |
| `b` | 前の単語へ |
| `e` | 単語の末尾へ |
| `0` | 行の先頭へ |
| `^` | 行の最初の文字へ |
| `$` | 行の末尾へ |
| `g` | 一番上へ |
| `G` | 一番下へ |
| `H`, `M`, `L` | 画面の上部、中央、下部へ |
| `Ctrl` + `f` | 1ページ下へ |
| `Ctrl` + `b` | 1ページ上へ |
| `Ctrl` + `d` | 半ページ下へ |
| `Ctrl` + `u` | 半ページ上へ |
| `f {文字}` | 次の指定文字へジャンプ |
| `t {文字}` | 次の指定文字の手前へジャンプ |

#### テキスト選択とコピー

| キー | 説明 |
|------|------|
| `v` | 文字選択モード |
| `V` | 行選択モード |
| `Ctrl` + `v` | 矩形選択モード |
| `y` | 選択範囲をコピー |
| `Enter` | 選択範囲をコピーしてコピーモード終了 |
| `Escape` / `q` / `Ctrl` + `c` | コピーモード終了 |

### その他の便利な機能

| キー | 説明 |
|------|------|
| `Cmd` + `c` | コピー |
| `Cmd` + `v` | 貼り付け |
| `Cmd` + `p` | コマンドパレット表示 |
| `Ctrl` + `Shift` + `p` | コマンドパレット表示 |
| `Ctrl` + `Shift` + `r` | 設定を再読み込み |
| `Alt` + `Enter` | フルスクリーン切り替え |
| `Ctrl` + `+` | フォントサイズを大きく |
| `Ctrl` + `-` | フォントサイズを小さく |
| `Ctrl` + `0` | フォントサイズをリセット |

## Neovim 入門ガイド

Neovim（nvim）は、Vimをベースにした高機能なテキストエディタです。

### Neovimの起動と終了

```bash
# ファイルを開く
nvim filename.txt

# Neovimを起動（新規ファイル）
nvim

# Neovimを終了
# （ノーマルモードで）:q Enter
# （変更を保存して終了）:wq Enter または :x Enter
# （変更を破棄して終了）:q! Enter
```

### Neovimの3つの基本モード

Neovimには主に3つのモードがあります：

#### 1. ノーマルモード（デフォルト）
- カーソル移動やコマンド実行を行うモード
- `Esc` キーを押すと、常にこのモードに戻れます

#### 2. インサートモード（入力モード）
- テキストを入力・編集するモード
- ノーマルモードから以下のキーで入入ります：
  - `i`: カーソル位置から入力開始
  - `a`: カーソルの次の文字から入力開始
  - `o`: 現在行の下に新しい行を作成して入力開始
  - `I`: 行の先頭から入力開始
  - `A`: 行の末尾から入力開始
  - `O`: 現在行の上に新しい行を作成して入力開始

#### 3. ビジュアルモード（選択モード）
- テキストを選択するモード
- ノーマルモードから以下のキーで入ります：
  - `v`: 文字単位で選択
  - `V`: 行単位で選択
  - `Ctrl` + `v`: 矩形選択

### 基本的な移動（ノーマルモード）

#### カーソル移動

| キー | 動作 |
|------|------|
| `h` | 左へ |
| `j` | 下へ |
| `k` | 上へ |
| `l` | 右へ |
| `w` | 次の単語の先頭へ |
| `b` | 前の単語の先頭へ |
| `e` | 単語の末尾へ |
| `0` | 行の先頭へ |
| `^` | 行の最初の文字へ |
| `$` | 行の末尾へ |
| `gg` | ファイルの先頭へ |
| `G` | ファイルの末尾へ |
| `{行番号}G` | 指定行へジャンプ（例: `10G` で10行目へ）|
| `Ctrl` + `d` | 半ページ下へ |
| `Ctrl` + `u` | 半ページ上へ |
| `Ctrl` + `f` | 1ページ下へ |
| `Ctrl` + `b` | 1ページ上へ |

### 基本的な編集（ノーマルモード）

#### テキストの削除

| キー | 動作 |
|------|------|
| `x` | カーソル位置の1文字を削除 |
| `dd` | 現在行を削除 |
| `dw` | カーソルから単語の末尾まで削除 |
| `d$` または `D` | カーソルから行末まで削除 |
| `d0` | カーソルから行頭まで削除 |

#### コピー・貼り付け

| キー | 動作 |
|------|------|
| `yy` | 現在行をコピー |
| `yw` | カーソルから単語の末尾までコピー |
| `y$` | カーソルから行末までコピー |
| `p` | カーソルの後ろに貼り付け |
| `P` | カーソルの前に貼り付け |

#### Undo・Redo

| キー | 動作 |
|------|------|
| `u` | 元に戻す（Undo）|
| `Ctrl` + `r` | やり直し（Redo）|

#### 検索・置換

| コマンド | 動作 |
|----------|------|
| `/検索文字列` | 前方検索 |
| `?検索文字列` | 後方検索 |
| `n` | 次の検索結果へ |
| `N` | 前の検索結果へ |
| `:s/old/new/` | 現在行の最初の"old"を"new"に置換 |
| `:s/old/new/g` | 現在行のすべての"old"を"new"に置換 |
| `:%s/old/new/g` | ファイル全体のすべての"old"を"new"に置換 |
| `:%s/old/new/gc` | 置換前に確認（c = confirm）|

### ファイル操作

| コマンド | 動作 |
|----------|------|
| `:w` | 保存 |
| `:w filename` | 名前を付けて保存 |
| `:q` | 終了 |
| `:wq` または `:x` | 保存して終了 |
| `:q!` | 保存せずに終了 |
| `:e filename` | ファイルを開く |
| `:sp filename` | 水平分割でファイルを開く |
| `:vsp filename` | 垂直分割でファイルを開く |

### ウィンドウ分割の操作

| コマンド/キー | 動作 |
|---------------|------|
| `:sp` | 水平分割 |
| `:vsp` | 垂直分割 |
| `Ctrl` + `w`, `h` | 左のウィンドウへ |
| `Ctrl` + `w`, `j` | 下のウィンドウへ |
| `Ctrl` + `w`, `k` | 上のウィンドウへ |
| `Ctrl` + `w`, `l` | 右のウィンドウへ |
| `Ctrl` + `w`, `w` | 次のウィンドウへ |
| `Ctrl` + `w`, `q` | ウィンドウを閉じる |
| `Ctrl` + `w`, `=` | ウィンドウサイズを均等に |

### よく使うその他のコマンド

| コマンド | 動作 |
|----------|------|
| `:set number` | 行番号を表示 |
| `:set nonumber` | 行番号を非表示 |
| `:set relativenumber` | 相対行番号を表示 |
| `:set hlsearch` | 検索結果をハイライト |
| `:noh` | 検索ハイライトを一時的に消す |
| `:help {キーワード}` | ヘルプを表示 |
| `:!{コマンド}` | シェルコマンドを実行 |

### Neovim 練習のヒント

1. **vimtutor を使う**: ターミナルで `vimtutor` と入力すると、対話型のチュートリアルが起動します
2. **最初は基本操作に集中**: `hjkl`での移動、`i`で入力、`Esc`でノーマルモード、`:wq`で保存終了を覚えましょう
3. **少しずつコマンドを覚える**: 一度にすべてを覚える必要はありません。よく使うものから徐々に覚えていきましょう
4. **マウスを使わない練習**: キーボードだけで操作することで、効率が大幅に向上します

### おすすめの学習ステップ

#### 第1週: 基本操作
- ノーマルモード、インサートモード、ビジュアルモードの切り替え
- `hjkl` でのカーソル移動
- `i`, `a`, `o` での入力開始
- `:w`, `:q`, `:wq` でのファイル操作

#### 第2週: 編集操作
- `dd`, `yy`, `p` での削除・コピー・貼り付け
- `u`, `Ctrl+r` での Undo/Redo
- `/` での検索と `n`, `N` での移動

#### 第3週以降: 効率化
- `w`, `b`, `e` での単語移動
- `0`, `$`, `gg`, `G` での行・ファイル移動
- `:s` での置換操作
- ウィンドウ分割の活用
